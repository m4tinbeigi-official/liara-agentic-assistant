## Why

حسابرسی فنی (Audit) تاریخ ۱۴۰۴/۰۶/۰۳ نشان می‌دهد هسته‌ترین وعده محصول — یعنی RAG عاملی روی مستندات لیارا — در نسخه فعلی **عملاً غیرفعال** است: پایگاه وکتور هرگز پر نمی‌شود (هیچ اسکریپت ایندکس‌سازی در مخزن وجود ندارد)، بنابراین `search_docs` همیشه خالی برمی‌گردد و عامل بی‌سروصدا به پاسخ‌های هاردکد سقوط می‌کند. سه اندپوینتِ مستندشده در `spec.md` (بخش ۴) نیز اصلاً پیاده‌سازی نشده‌اند. ضمناً بیلد داکر به‌خاطر نبود `package-lock.json` روی `npm ci` شکست می‌خورد و ایمیج نهایی به دلیل `torch` سنگین‌تر از حد مجاز PaaS است.

## What Changes

- ساخت خط لوله ایندکس‌سازی (`ingest.py`) که مستندات لیارا را از GitHub کلون/به‌روزرسانی کرده، MDX فرانت‌مترها را پاک‌سازی، بر اساس سکشن چانک‌بندی و با متادیتای عمیق (URL منبع، عنوان سکشن، پلتفرم) در Qdrant ذخیره کند.
- ارتقای جست‌وجو به Hybrid واقعی (Dense + BM25 با RRF Fusion) مطابق ADR-001، همراه با Citations ساختاریافته (لینک مستقیم سکشن مرجع) در پاسخ نهایی.
- تکمیل سطح API مستندشده: `POST /api/v1/agent/diagnose`، `POST /api/v1/agent/generate-config` و `GET /api/v1/docs/search`.
- سخت‌سازی استقرار: جایگزینی sentence-transformers/torch با fastembed (ONNX)، Healthcheck داکر، کاربر non-root، و heartbeat سمت SSE برای سازگاری با Load Balancer لیارا.
- رفع مسیرهای مرجع خراب: حذف/تکمیل سرورهای MCP تعریف‌شده در `mcp.json` که به فایل‌های ناموجود اشاره می‌کنند، و اصلاح دستور اجرای محلی README.

## Capabilities

### New Capabilities
- `docs-ingestion`: خط لوله همگام‌سازی و ایندکس مستندات رسمی لیارا از مخزن GitHub با چانک‌بندی آگاه از ساختار Markdown.
- `api-surface`: سه اندپوینت مستندشده اما پیاده‌سازی‌نشده، به همراه قرارداد خطا و اعتبارسنجی Pydantic.
- `deployment-hardening`: کاهش حجم ایمیج، سلامت‌سنجی، امنیت runtime و تاب‌آوری SSE روی PaaS.

### Modified Capabilities
- `vector-search`: ارتقا از جست‌وجوی برداری تنها به Hybrid Search (Dense + BM25 + RRF) با خروجی ساختاریافته و ارجاع مستقیم؛ رفتار fallback حفظ می‌شود اما دیگر حالت پیش‌فرض دائمی نیست.

## Impact

- **Backend:** ماژول جدید `ingestion.py` و `retrieval.py`؛ تغییر امضای `search_docs` به بازگشت ساختار داده (dict list) به‌جای رشته خام؛ دو اندپوینت جدید در `main.py`.
- **Frontend:** بدون تغییر شکسته؛ رندر Citation Badge برای نتایج RAG اختیاری و سازگار با نسخه فعلی.
- **Deployment:** کاهش محتمل حجم ایمیج از ~۵GB به ~۳۰۰MB با حذف torch؛ نیازمند یک بار اجرای `python ingest.py` پس از Deploy اولیه (Job یا startup hook).
- **Tests:** افزودن تست قراردادی برای اندپوینت‌های جدید و تست کیفیت بازیابی (Recall@3) روی مجموعه کوئری طلایی.
