## Why

پروژه فعلی Liara Agentic Copilot به عنوان یک پروتوتایپ اولیه (MVP) پیاده‌سازی شده است که بدون کلید API کار می‌کند. برای تبدیل آن به یک محصول واقعی، توسعه‌پذیر و کاملاً کاربردی، نیازمند بازنویسی معماری و پیاده‌سازی سرویس‌های واقعی هستیم. این توسعه به ما امکان می‌دهد دیتابیس برداری (Vector DB) برای RAG محلی، یک معماری Backend قدرتمند بر پایه FastAPI یا Node.js پیشرفته، و رابط کاربری کامل‌تر با امکان اتصال به API پلتفرم لیارا را فراهم کنیم.

## What Changes

- استقرار یک موتور پایدار برای RAG (نظیر Qdrant یا ChromaDB روی دیسک لیارا) جهت جست‌وجوی عمیق مستندات لیارا به جای Mocking فعلی.
- بازنویسی Backend به یک معماری مدرن (همچون استفاده از Agent Frameworkهای پیشرفته مانند LangGraph یا پیاده‌سازی‌های Custom ReAct).
- ادغام احراز هویت با استفاده از Liara API Token برای مدیریت عملیات‌های ابری (Deploy، Logs) مستقیماً از داخل دستیار.
- ارتقای رابط کاربری برای نمایش زنده (Streaming) پاسخ‌ها و لاگ‌ها، با استفاده از React/Next.js یا بهبود نسخه فعلی Vanilla.
- پشتیبانی از سناریوهای گسترده‌تر عیب‌یابی (Troubleshooting) برای پلتفرم‌های مختلف با استفاده از داده‌های واقعی.

## Capabilities

### New Capabilities
- `agent-workflow`: سیستم تصمیم‌گیری و مسیردهی Agent مبتنی بر ReAct و ابزارهای جست‌وجو، کانفیگ‌ساز و تحلیل‌گر.
- `vector-search`: سرویس ایندکس و جست‌وجوی برداری ترکیبی (Hybrid Search) روی مستندات Markdown لیارا.
- `cloud-ops`: امکان احراز هویت، دریافت لاگ‌های زنده و دیپلوی مستقیم با استفاده از Liara API.
- `interactive-ui`: کامپوننت‌های پیشرفته رابط کاربری جهت استریم پاسخ‌ها، دکمه‌های اجرای سریع و کپی کدهای کانفیگ.

- (این یک بازنویسی پایه‌ای است، بنابراین Capability‌های موجود به طور کامل در معماری جدید در New Capabilities بازتعریف می‌شوند.)

## Impact

- **Backend:** اضافه شدن وابستگی به Vector DB و فریم‌ورک‌های LLM.
- **Frontend:** نیاز به بازنویسی UI با React یا فریم‌ورکی مشابه برای پشتیبانی از ارتباطات Streaming و State پیچیده.
- **Deployment:** تغییر تنظیمات Docker و `liara.json` برای اختصاص دیسک دائمی به Vector DB و تنظیم متغیرهای محیطی API.
