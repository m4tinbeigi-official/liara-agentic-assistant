# راه‌اندازی دیتابیس PostgreSQL

در پلتفرم ابری لیارا، شما می‌توانید با یک کلیک دیتابیس PostgreSQL بسازید. پس از ساخت، یک `URI` اتصال در اختیار شما قرار می‌گیرد که شامل نام کاربری، رمز عبور و هاست است.

**نحوه اتصال:**
1. به صفحه دیتابیس خود در پنل لیارا بروید.
2. URI را کپی کرده و به عنوان متغیر محیطی (مثلاً `DATABASE_URL`) در تنظیمات برنامه خود وارد کنید.

خطاهای رایجی مانند `Connection Refused` معمولاً به دلیل اشتباه وارد کردن رمز عبور یا عدم تنظیم صحیح URI در بخش متغیرهای محیطی است.
