# ذخیره‌سازی فایل‌ها در لیارا

سیستم‌فایل برنامه‌ها در لیارا **فقط-خواندنی (Read-Only)** است. به این معنا که اگر کاربر شما عکسی آپلود کند، پس از هر بار Deploy یا ری‌استارت برنامه، آن عکس حذف خواهد شد.

برای ذخیره فایل‌های آپلودی یا دیتابیس‌های فایلی (مثل SQLite)، باید از **دیسک (Disk)** استفاده کنید.

نمونه کانفیگ دیسک در `liara.json`:
```json
{
  "app": "my-app",
  "disks": [
    {
      "name": "data-volume",
      "mountTo": "/app/uploads"
    }
  ]
}
```
پس از تعریف، برنامه شما تنها مجاز است در پوشه `/app/uploads` بنویسد. خطای `Read-only file system` دقیقاً به همین موضوع اشاره دارد.
